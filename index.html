Edge of Sync

Collective transitions in dancing groups

This project models the transitions in a closed-loop feedback system of human-to-human and human-to-audio coupled oscillations, where group movement generates music in real time alongside heart rate and both limb and agent-center locations. It asks when and how the collective shifts between synchrony states, whether those shifts track markers of altered states of consciousness (heart rate) with persistence (a psychological instrument), and whether collective synchrony carries longer-term consequences for wellbeing. Modeling aims are mechanistic specificity of transitions, estimating how near a transition the system is, and whether groups regulate that distance.

This project uses two complementary models. The first is a computational model that generates these dynamics from first principles, led by adaptive-network Kuramoto (coupling that evolves to capture learning and regulation), with the swarmalator family and Couzin/zonal models adding spatial movement. A web application, fed from the project’s GitHub repository, will provide an interface to work with the models. The second is a data-driven analysis model with video recordings of human groups dancing that are turned into per-dancer movement signals, which feed a pipeline that detects collective states, transitions, coupling, and early-warning signals directly from the recordings.

Two models

One generates collective transitions from first principles; the other finds them in recordings of real groups.
